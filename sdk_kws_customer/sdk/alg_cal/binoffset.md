# DTOF RefBinOffset 校准流程说明

## 1. 功能概述
RefBinOffset校准用于调整参考光路的时序窗口位置，确保参考光信号能够被完整采集。

## 2. 校准流程

### 2.1 初始化准备
- 配置参考光路SPAD为全开状态
- 初始化相关寄存器配置

### 2.2 粗调过程
1. 设置搜索参数：
   - 总搜索范围：256 bins
   - 搜索步进：32 bins
   - 搜索窗口大小：64 bins

2. 粗调搜索：
   - 从0开始，按32 bins步进遍历整个搜索范围
   - 每个位置采集一帧数据
   - 寻找信号峰值最大的位置
   - 记录最佳峰值位置

3. 初步定位：
   - 在最佳峰值位置前移半个步进（16 bins）
   - 设置此位置为粗调结果

### 2.3 精确定位
1. 在粗调位置采集100帧数据
2. 对100帧数据进行平均处理
3. 在平均数据中找出精确的峰值位置
4. 计算最终的BinOffset：
   - BinOffset = 粗调位置 + 精确峰值位置 - 29

### 2.4 结果确认
1. 设置计算得到的BinOffset值
2. 验证参考光信号是否在合适的位置

## 3. 关键参数
- `BIN_BUFFER_SIZE`: 64（采样窗口大小）
- `TOTAL_BIN_LENGTH`: 256（总搜索范围）
- `OFFSET_STEP`: 32（搜索步进）
- `FRAME_COUNT`: 100（精确定位时的平均帧数）
- `BIN_OFFSET_SUB`: 29（固定偏移补偿值）

## 4. 注意事项
1. 校准过程需要确保参考光路工作正常
2. 搜索过程中需要避免环境光干扰
3. 最终的BinOffset值需要在合理范围内
4. 建议在温度稳定的环境下进行校准

## 5. 优化建议
1. 可以增加窗口能量计算功能
2. 根据能量变化趋势提前结束搜索
3. 可以增加峰值有效性判断
4. 考虑添加温度补偿机制
