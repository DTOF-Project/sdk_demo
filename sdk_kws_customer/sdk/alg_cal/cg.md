# DTOF CG (串扰) 校准流程说明

## 1. 功能概述
CG（Crosstalk/串扰）校准用于测量和补偿系统中的光学串扰，提高测距精度。

## 2. 校准流程

### 2.1 数据采集阶段
1. 参数准备：
   - 保存原始闪光计数值（maxfls）
   - 配置校准用闪光计数（0x4000）
   - 设置采样帧数（不超过最大帧数限制）

2. 数据采集：
   - 循环采集指定帧数
   - 每帧读取前32个bin的数据
   - 对每个bin位置的数据进行累加
   - 计算平均值（除以帧数）

### 2.2 数据处理阶段
1. 数据预处理：
   - 每3个相邻bin取平均值
   - 生成16个新的bin数据

2. DC值计算：
   - 在16个bin中找出最大值
   - 向上取整（基数256）
   - 进行归一化处理（考虑闪光计数）

3. AC值计算：
   - 对每个bin数据进行归一化
   - 每两个bin组合成一个参数
   - 生成8个AC参数

## 3. 关键参数
- `CROSS_TALK_BIN_SIZE_NEW`: 32（采样bin数）
- `CROSS_TALK_CALIB_FLASH_CNT`: 0x4000（校准闪光计数）
- `CROSS_TALK_TEMP_SIZE`: 16（中间数据大小）
- `CROSS_TALK_PARAM_SIZE`: 8（最终参数个数）
- `VAL_BOOST_MULTIPLE`: DC值提升倍数

## 4. 注意事项
1. 校准环境要求：
   - 确保无外部光干扰
   - 温度稳定
   - 距离合适

2. 数据有效性检查：
   - 采样数据范围检查
   - 计算结果合理性验证
   - 参数归一化正确性

3. 硬件配置：
   - 正确配置闪光计数
   - 确保数据读取地址正确
   - 恢复原始配置

## 5. 优化建议
1. 数据处理优化：
   - 可以考虑添加异常值过滤
   - 优化平均值计算方法
   - 改进归一化算法

2. 稳定性提升：
   - 添加温度补偿
   - 增加数据有效性验证
   - 优化参数计算方法

## 6. 输出结果
- bin_data: 中间过程数据
- ac_data: AC串扰参数（8个）
- dc_data: DC串扰参数（1个）
