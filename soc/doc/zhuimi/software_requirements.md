# 追觅新增软件需求

## 1. 修改环境光补偿算法

原因：目前近距离高反瓷砖测试不满足客户要求+-4mm精度
方案：在原有kws环境光补偿算法基础上，触发阈值*10
时间：2026/3/18

## 2. 修改ref默认值

原因：当前ref配置为254，效果不好
方案：默认值修改为252
时间：2026/3/19

## 3. 修改环境光补偿算法
原因：1.中的修改发现补偿值过高且不准确
方案：在原有kws环境光补偿算法基础上，触发阈值*6，补偿值/6
时间：2026/3/20

## 4. 增加低低功耗模式，增加双模式校准
原因：原有120Hz模式近距离高反瓷砖测试还是不满足客户要求+-4mm精度
方案：原有120Hz模式定义为低功耗模式，DRV_IPK = 6，PG_TRIM = 4（牺牲远距离探测能力）
      增加低低功耗模式，DRV_IPK = 6，PG_TRIM = 6
      ft校准要把两种模式的值都保存，30Hz使用OTP校准值
时间：2026/3/20

软件原方案：校准后把ft数据存到flash，同时加载到内部mcu，上电之后读flash，有数据则使用flash数据，无数据使用otp/默认值（芯片没做过ft）
修改后方案：1. 校准时分为低功耗和低低功耗，存两组数据
           2. 校准完之后不做加载，还使用otp/默认值（芯片没做过ft），切回30Hz
           3. 增加cmd切换低功耗和低低功耗，配置相应的ft数据和DRV_IPK/PG_TRIM
